# Goalivo

Goalivo is a live football companion app for scores, fixtures, lineups, match stats, notifications, favorites, and fan features.

## Store Identity

- App name: Goalivo
- Android application ID: `com.goalivo.app`
- iOS display name: Goalivo
- Brand tagline: Achieve More

## App Store Short Description

Live football scores, fixtures, lineups, stats, alerts, and fan features.

## App Store Full Description

Goalivo keeps football fans close to every match with live scores, fixtures, team details, lineups, match events, standings, and smart alerts.

Follow today's games, browse teams and leagues, save your favorite clubs, and open match detail pages for richer context including events, lineups, statistics, ratings, and fan-focused features.

Key features:
- Live football scores and fixtures
- Match detail pages with events, lineups, and stats
- Team and league browsing
- Favorites and goal alerts
- Notification preferences
- Dark and light themes
- Fan-focused community, predictions, quiz, and XP features

Goalivo is built for fans who want football updates that are fast, clean, and easy to follow.
